# skill-perfil-google-empresas

Skill do Claude e material de apoio para criar e otimizar perfis de clientes no Google Empresas (Google Business Profile): elegibilidade, pesquisa de termos, preenchimento, verificação, avaliações e pesquisa nas IAs.

Este repositório não contém dados de clientes. Os exemplos são anonimizados e servem só para ilustrar situações diferentes.

## Para quem é

Agências, freelancers e profissionais que montam ou otimizam perfis no Google para outras empresas e querem um processo repetível, que separa:

1. **Regras do Google**, que valem para todo caso.
2. **Decisões por cliente**, com opções e critérios. Quem decide é o cliente.
3. **Fluxo da agência**, que cada um adapta ao seu jeito de trabalhar.

## Como usar a skill

**Claude Code:** abra este repositório no Claude Code. A skill em `.claude/skills/` fica disponível no projeto.

**Outros usos:** os arquivos em `docs/` funcionam sozinhos, como material de consulta.

## Princípios

- A pesquisa vem antes do texto. Nome e descrições partem dos termos e das frases que o público de fato usa, não do vocabulário interno do negócio.
- A pesquisa nas IAs é feita como uma pessoa faria, no navegador, logado, sem API.
- Nada aqui promete resultado. Os números de antes e depois são correlação, e só são divulgados com consentimento do cliente.
- As regras do Google mudam. Confira sempre a ajuda oficial antes de afirmar algo ao cliente.

## Aviso

Este material é de apoio e não é aconselhamento jurídico. Revise contratos e autorizações com um profissional.
