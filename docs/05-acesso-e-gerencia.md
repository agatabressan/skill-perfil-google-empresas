# 5. Acesso e gerência

## Princípio

O cliente é o proprietário principal do perfil e a agência é gerente. Só existe um proprietário principal, e ele pode ser transferido.

O gerente só pode ser adicionado depois que o perfil existe. Confirme na prática, a cada caso, se o convite é possível antes ou depois da verificação.

## Dois caminhos para criar o perfil

### A. O cliente não quer compartilhar credenciais

1. O cliente cria ou loga na própria conta, numa call ou orientado por você.
2. A agência conduz o preenchimento, com o cliente logado, ou passa as instruções.
3. Com o perfil criado, o cliente convida a agência como gerente.

### B. O cliente aceita compartilhar credenciais

1. Registrar o aceite por escrito (ver `09-contrato-checklist.md`).
2. A agência cria e preenche pela conta do cliente.
3. O cliente troca a senha logo depois.
4. Mesmo assim, a agência vira gerente ao final. Assim o acesso contínuo não depende de uma senha compartilhada.

Observações:

- Ao logar em dispositivo novo, o Google pode pedir código enviado ao celular do cliente. Combine antes.
- Nunca digite a senha do cliente por ele, e nunca contorne CAPTCHA.
- Prefira que o perfil nasça no e-mail do cliente, para não precisar transferir depois.

## Por que continuar como gerente mesmo com as credenciais

Porque a senha compartilhada é provisória e deve ser trocada. O papel de gerente mantém o acesso da agência sem depender dela, e deixa o cliente com a propriedade.

## Encerramento

Combinar no contrato o que acontece com o acesso de gerente quando o trabalho termina.
