# 10. Modelo de tarefa e de página de planejamento

Modelo para gerenciador de tarefas (Notion, Trello, planilha). Duplique por cliente.

## Tarefa

**Título:** Criar perfil no Google Empresas: [cliente]

Campos sugeridos: projeto ou cliente, status, responsável, data prevista (a data do vídeo de verificação, se houver), prioridade.

Checklist:

- [ ] Elegibilidade confirmada (contato presencial, endereço, local de terceiros)
- [ ] Verificado no Maps se já existe perfil ou duplicado
- [ ] Coleta de informações completa
- [ ] Pesquisa de termos e benchmark feita
- [ ] Linha de base nas IAs registrada
- [ ] Decisões por cliente fechadas (endereço, horário, preço, nome, acesso)
- [ ] Autorização ou contrato registrados
- [ ] Logo, capa e fotos recebidos
- [ ] Perfil preenchido
- [ ] Verificação orientada e agendada
- [ ] Gerência da agência adicionada
- [ ] Material de avaliações entregue
- [ ] Pesquisa nas IAs repetida em 30, 60 e 90 dias

## Página de planejamento

Seções:

1. **Objetivo**
2. **Decisões tomadas** (com data)
3. **O que falta** (checklist)
4. **Passo a passo planejado**
5. **Registro de decisões** (tabela de data e decisão)

Linke a página à tarefa e destaque na tarefa o que falta, para nada se perder.
